# Use koinon

Start with the knowledge shared with you. Library organizes the organization's sources; Chat helps you ask questions and inspect the evidence behind an answer. Your permissions determine which content and actions are available.

## Find your way around

The [visual walkthrough](interface-tour.md) follows the interface from sign-in through an answer and its sources. For your name, photo, language and personal API tokens, read [your profile](../operations/profiles-and-tokens.md).

## Work with the library

Use the [Library guide](library.md) to navigate workspaces, projects and folders, filter a listing and inspect a resource. Before an import, check [supported files and formats](intake-formats.md). The [versions and lineage guide](lineage.md) explains recorded revisions and the source of a document or dataset value.

## Ask a question and check the evidence

Read [Agents and chat](agents.md) for conversations and answers. Open an answer's audit to understand its recorded sources and execution. [Exports, sharing and sources](exports-sharing.md) covers what can be downloaded or shared and how recipient access is checked.

## Configure or integrate the product

Organization administrators can follow [Administration](configuration-overview.md). Developers can start with [Integrate](integrations.md); deployment and recovery belong in [Operations](../operations/README.md).
