# Operations

firefly koinon runs as a headless API. Forge and other applications can use REST or the SDK without deploying the Angular frontend. The backend owns authorization, catalog scope, durable jobs and shared sessions; installing a UI does not change those controls.

Read [local deployment](local-deployment.md), [migrations](migrations.md), [production](production.md), and [backup and recovery](backup-restore.md). [Qualification](qualification.md) separates observed local behavior from untested templates and external providers.
