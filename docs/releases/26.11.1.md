# koinon 26.11.1

koinon 26.11.1 aligns the backend, native document/structured/storage packages, Python/TypeScript/Java SDKs, Angular library and desktop MCP extension under CalVer `YY.MM.Patch`. The runtime uses official pyfly 26.10.32, pinned to its tested release commit.

A declarative installation manifest configures the product identity and retained default knowledge spaces. Apply native migrations 36 and 37 and current operator/runtime grants before enabling the installation workflow. Runtime identities cannot reseed or reset the installation ledger. See [first start](../operations/first-start.md).

Chat opens after sign-in, with Library second. Settings and Activity pages are available to organization administrators through the avatar menu. Sign-out asks for confirmation and checks the native session after the server response. Existing authenticated shared-answer links retain their explicit receipt during initialization.

Library keeps Add knowledge and exposes contextual creation. Nested folders inherit their knowledge space and project. System spaces and folders cannot be deleted, archived or moved. Ordinary folder moves use a fresh parent and update timestamp, remain inside the same space and project, and preserve source identities. Chat projects continue to organize private conversations with explicit memory opt-in. Read [Library](../guides/library.md) for the supported boundaries.

Use matching runtime wheels and integration packages from [GitHub Releases](https://github.com/fireflyframework/firefly-koinon/releases). Preserve the release checksums, migration record and installation configuration. Source checks, installed-package qualification and authenticated acceptance in a deployment are separate records.
