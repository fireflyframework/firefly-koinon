# koinon 26.11.11

!!! note "Release candidate"
    These notes describe the prepared source version. Release artifacts, their checksums and installed-package verification are separate gates. The published desktop download walkthrough remains pinned to 26.11.10 until the new archives are available.

## Organize your own Library

New installations start with an empty Library. Create the spaces, projects and folders that fit your team; koinon no longer creates predefined or protected knowledge folders, including Signature folders. Existing folders and their contents remain in place. Authorized users can reorganize them through the ordinary catalog actions, while installation provenance remains immutable.

The Library fills the available page height, including empty and short lists. Its background context menu offers actions for the current location; item menus apply to the selected item. Available actions still follow the same server permissions. See the [Library guide](../guides/library.md).

## Add files with clearer feedback

The upload capability contract reports the formats and limits supported by the installation's available parsers. The picker groups familiar formats such as Word, Excel, PowerPoint, PDF and tabular files, with individual file sizes and reasons for rejected files. Queued uploads distinguish transfer, processing, cancellation, failure and an outcome that still needs confirmation. An uncertain write is not automatically replayed.

Format hints do not replace server validation or establish that a file is ready to search. Follow [file ingestion](../reference/library-file-ingestion.md) and inspect the recorded result before retrying a failed or uncertain operation.

## Connect the desktop bridge through browser sign-in

The desktop MCPB source supports explicit browser OAuth with an operator-registered public client and an exact local callback. Sign-in starts only when the user requests it. Tokens stay in bridge memory; restart, expiry or revocation requires reconnecting. Additional scopes require consent, and the bridge never replays the original operation automatically.

Personal access tokens remain an explicit compatibility mode. Existing MCPB PAT configurations must select `pat` when upgrading. Server permissions remain authoritative in both modes. See [desktop OAuth](../integrations/desktop-oauth.md) for registration, reconnect and revocation steps. Controlled protocol checks do not establish acceptance in an installed Claude client or a hosted connector.

## Reduce repeated reads and qualify worker isolation

Knowledge and answer paths reuse bounded policy observations, batch catalog ancestry reads and validate audit memory at the final boundary. Conversation capacity is bounded separately from background-worker capacity. These changes reduce redundant work without relaxing authorization or claiming a deployment-specific response-time improvement.

PostgreSQL integration coverage exercises concurrent claims in separate worker processes, overlapping native document parsing, exclusion of a third claim at the configured limit, and cancellation fencing for one batch without replaying another. This is controlled worker qualification, not a cloud-scaling or production-capacity result.

## Update the installation

Use `26.11.11` across runtime packages, canonical SDKs and interface assets. This candidate retains pyfly `26.10.32`; it does not claim adoption of a later framework release.

Apply native migration `koinon_0043_ordinary_folders` through the separate migration process before starting the updated application. It retires special folder protection while preserving existing content, identities and installation receipts. It does not delete folders or create a replacement default structure. An image-only update is insufficient.

Back up the database and rehearse the exact upgrade on a restored copy. Follow [schema and role changes](../operations/migrations.md), then verify API and worker readiness, authorized folder operations, ingestion and an evidence-backed conversation. Preserve original files, source versions, conversation evidence and email delivery history; this release does not claim new email delivery or replay earlier messages.
