# koinon 26.10.2

koinon 26.10.2 makes PostgreSQL the default shared cache and uses pyfly 26.10.31. Document and structured services use native cache adapters for replay responses, rolling rate limits and corpus pages. The default local and managed installation reuses the primary database instead of requiring a Redis service.

Native migration 34 adds the framework's rolling-window table. Existing cached values, knowledge, source evidence and administrator grants are preserved. Apply the release migration bundle and current role grants before restarting the API and workers.

Native migration 35 adds an encrypted, installation-scoped initial-welcome ledger. An operator can admit fresh verified contacts for exact pending direct-Entra administrator grants. The existing worker sends one branded HTML and plain-text welcome without requiring ongoing directory synchronization; signed SSO still activates access. Expired contacts and uncertain provider outcomes are never automatically replayed. Read [initial administrator welcome](../reference/bootstrap-welcome.md) for the operator workflow and its delivery limits.

The [shared-cache guide](../operations/postgresql-cache.md) explains configuration, namespace isolation, expiry, cleanup, replica coordination and failure behavior. Backend, SDK, Angular and desktop package versions remain aligned at 26.10.2; this release does not change the public API operation set.

Requests and isolated MCP tasks keep the transaction registry of their own application. This preserves database ownership when multiple application contexts share a process, including middleware and streamed responses. MCP authentication still starts in a fresh task without inherited browser identity or an outer transaction.

Download the matching distributions and checksums from [GitHub Releases](https://github.com/fireflyframework/firefly-koinon/releases). Keep source validation, installed-package qualification and your deployment's authenticated acceptance records with the installation. See [first start](../operations/first-start.md) for the complete setup order.
