# koinon 26.11.6

## Preserve authorization during queued ingestion

Queued document processing restores the original request's canonical identity and token restriction before entering the knowledge services. A worker keeps the same tenant, destination and source reservation throughout the operation. Missing or malformed identity context stops processing; it does not acquire a different identity or bypass authorization.

An uploaded original and searchable knowledge are separate stages. Keep the original batch when processing fails and inspect its current state before taking another action. The [upload and update journey](../guides/user-journeys.md) explains these stages and the [bulk intake guide](../guides/bulk-intake.md) describes the available recovery controls.

## Search while other documents are processing

A broad knowledge search now excludes documents whose ingestion is unfinished. One pending document no longer prevents searching other authorized, ready documents. Selecting a pending document directly reports that it is not ready. A ready document with a missing domain binding remains an error that requires investigation.

When no eligible sources exist, the recorded search outcome contains no invented citations or model-derived replacement knowledge. The assistant can explain the lack of evidence without presenting an unsupported answer.

## Package and deployment compatibility

Use version `26.11.6` consistently across runtime packages, SDKs and interface assets. The qualified runtime remains pyfly `26.10.32`. Preserve the existing installation identity, uploaded originals and migration history when updating. Follow [installation](../operations/installation.md) and [migration checks](../operations/migrations.md) before resuming work.

Source tests, installed packages, hosted checks and deployed ingestion each have their own verification results. Inspect the running installation and its retained jobs after updating; a published package does not by itself establish that an earlier failed job has completed.
