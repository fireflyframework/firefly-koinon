# firefly koinon

This package supplies reusable instructions and branded assets. It does not create a connection, register a client, grant access or approve a change. Connect your own authorized koinon account using your operator's HTTPS endpoint. Use OAuth for a hosted connection; the separately distributed desktop extension is a PAT alternative.
